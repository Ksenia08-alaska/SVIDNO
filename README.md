# SVIDNO

Одностраничный сайт SVIDNO HOUSE — продажа комплекса у воды в д. Свидно, Логойский район.
Сайт: https://svidno.svhouse-api.by

Чистые HTML/CSS/JS без сборки — работает на Vercel как есть.

## Структура

```
index.html            вся страница
css/styles.css        стили и адаптив (телефон / планшет / ПК)
js/main.js            интерактив: меню, вкладки, галерея, ролик с дрона, YouTube
images/*.webp         фото в полном размере
images/thumbs/*.webp  уменьшенные копии (720 px) для сеток и превью
images/hero.jpg       картинка для превью ссылки в мессенджерах (og:image)
video/aerial-0N-hd.mp4  5 кадров с дрона, без звука (1920×1080 для ПК)
video/aerial-0N-m.mp4   те же кадры 1280×720 (для телефонов)
video/aerial-0N-poster.webp  первый кадр каждого ролика
video/youtube-poster.webp  обложка видеообзора
```

## Ролик с дрона

Пять разных кадров идут по кругу без звука, со сменой через плавное затухание.
Кнопка паузы — справа внизу, переключение — по полоскам сверху или свайпом.
Вне экрана и в фоновой вкладке ролик сам встаёт на паузу.

Порядок и подписи задаются атрибутами `data-src` / `data-title` у кнопок `.reel-seg` в `index.html`.
